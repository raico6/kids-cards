# 儿童英语字母卡片

给幼儿用的 A–Z 英语闪卡。点字母看卡片、听英文发音。

线上地址：https://raico6.github.io/kids-cards/

## 怎么用

1. 打开首页，点一个字母。
2. 换卡片时不会自动读。点下方的 🔊 听发音；左右滑动，或点 ◀ ▶ 换卡片。
3. iPhone / iPad 请先关闭静音并调高音量。

## 家长设置

首页右下角「⚙︎ 家长」要**长按约 1.5 秒**才进入设置。短按只会提示「家长请长按 1.5 秒进入设置」。

设置里可以按字母改英文单词、中文意思和 emoji，添加单词，下载卡片 PNG，导入或导出 JSON，或恢复默认。修改会自动保存在本机浏览器。

## 本地打开

在仓库根目录起一个静态服务器，例如：

```bash
python3 -m http.server 8080
```

然后访问 http://localhost:8080/
